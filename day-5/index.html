02
The dev part

Same API, every model

fit, then predict. That’s it.

In scikit-learn every algorithm follows the same interface, so switching from a decision tree to a random forest is a one-line change. One interface, many implementations.

# every scikit-learn model has the same interface
model = RandomForestClassifier()   # swap this one line
model.fit(X_train, y_train)        # learn
model.predict(X_test)              # predict
model.score(X_test, y_test)        # check
03
The cheat sheet

Every algorithm, one sentence

What it does, the dev version, and its weak spot

Classic machine learning in nine cards.

  • Logistic regressionone sentence

    A weighted vote of the features, squashed into a probability.

    Dev: A scoring function with an if-statement at the end

    Watch out: Draws straight-line boundaries only.

    scikit-learn
    from sklearn.linear_model import LogisticRegression model = LogisticRegression()

  • K-nearest neighboursone sentence

    Find the k most similar examples and copy their answer.

    Dev: Show me your 5 nearest neighbours and I’ll guess what you are

    Watch out: Slow on big data, and needs feature scaling.

    scikit-learn
    from sklearn.neighbors import KNeighborsClassifier model = KNeighborsClassifier()

  • Decision treeone sentence

    A flowchart of yes/no questions learned from the data.

    Dev: A learned nested if-else

    Watch out: One deep tree overfits easily.

    scikit-learn
    from sklearn.tree import DecisionTreeClassifier model = DecisionTreeClassifier()

  • Random forestone sentence

    Hundreds of trees on random slices of the data, voting.

    Dev: Many reviewers voting on a PR

    Watch out: Bigger and slower, harder to explain.

    scikit-learn
    from sklearn.ensemble import RandomForestClassifier model = RandomForestClassifier()

  • Gradient boosting / XGBoostone sentence

    Trees built one after another, each fixing the last one’s mistakes.

    Dev: Every commit fixes the bugs the last one left

    Watch out: Can overfit if you train too long.

    scikit-learn
    from sklearn.ensemble import GradientBoostingClassifier model = GradientBoostingClassifier()

  • Support vector machineone sentence

    Draws the widest possible gap between two groups.

    Dev: Maximum safety margin between two services

    Watch out: Slow on large datasets; needs scaling.

    scikit-learn
    from sklearn.svm import SVC model = SVC()

  • Naive Bayesone sentence

    Probability-based guessing that treats each feature as independent.

    Dev: A spam filter counting suspicious words

    Watch out: The independence assumption is rarely true, yet it often works.

    scikit-learn
    from sklearn.naive_bayes import GaussianNB model = GaussianNB()

  • K-meansone sentence

    Groups unlabelled data into k clusters around centre points.

    Dev: Auto-sharding users by similarity

    Watch out: You have to choose k yourself.

    scikit-learn
    from sklearn.cluster import KMeans model = KMeans()

  • PCAone sentence

    Compresses many columns into a few that keep most of the information.

    Dev: Lossy compression for your features

    Watch out: The new columns are hard to interpret.

    scikit-learn
    from sklearn.decomposition import PCA model = PCA()
