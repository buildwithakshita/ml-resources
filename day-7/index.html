02
The cheat sheet

Six ideas, that's all

What it is, the dev version, and the trap

Every neural network, from a spreadsheet to ChatGPT, is built from these.

  • Neuronthe building block

    Takes inputs, multiplies each by a weight, adds a bias, then squashes the result through an activation function. Weights are how much it trusts each input.

    Dev: A function with tunable config values

    Watch out: It's loosely inspired by the brain, not a copy of it.

    Formula
    a = σ(w1x1 + w2x2 + b)
    a = sigmoid(w1*x1 + w2*x2 + b)

  • Layersstacked neurons

    Neurons side by side form a layer; layers stacked form a network. Early layers find simple patterns, later layers combine them.

    Dev: A pipeline where each stage refines the last

    Watch out: More layers isn't automatically better.

    Shape
    inputs → hidden → hidden → output

  • Forward passmaking a guess

    Data flows in, through each layer, and out comes a guess.

    Dev: Calling the function

    Watch out: With random starting weights, the first guesses are nonsense.

    Flow
    input → layers → guess

  • Losshow wrong

    One number for how wrong the guess was. Training just means making this number small.

    Dev: The number of failing tests

    Watch out: A low training loss can still mean overfitting.

    Goal
    make L as small as possible

  • Gradient descentwalking downhill

    For every weight, ask “if I nudge this up a little, does the loss go up or down?” Then nudge it the way that lowers the loss. Like walking downhill blindfolded by feeling the slope.

    Dev: Tuning one config value at a time, keeping what helps

    Watch out: The step size (learning rate) can make or break it.

    One learning step
    w ← w − η · ∂L∂w
    w = w - lr * grad

  • Backpropagationpassing blame

    The efficient way to get that slope for every weight at once, by passing blame backward from the output to the input, layer by layer.

    Dev: A stack trace for blame: how much did each line cause the bug?

    Watch out: Backprop finds the slopes; gradient descent takes the step.

    Direction
    output → hidden → input
    loss.backward()
Bonus Learning rate (η): how big each downhill step is. Too big and you leap past the bottom and bounce around forever. Too small and training takes ages. Just right and the loss slides down smoothly.
03
Watch out

Three things people get wrong

So you don't say them on camera

  1. “Generation 1 vs 500” usually isn't backpropMost Snake and Flappy Bird “generation” videos use neuroevolution: many random networks play, and the best are copied with small random changes. Gradient descent trains in epochs, not generations.
  2. A neural network is not a brainIt's loosely inspired by one. It's maths: multiply, add, squash, repeat.
  3. Training longer isn't always betterPast a point the network memorises the training data and gets worse on new data. That's overfitting.
04
Self-check

Say these out loud

If you can answer all five, you've got it

  1. What does a single weight represent?
  2. Why do we need a loss function at all?
  3. Explain gradient descent with the hill, in two sentences.
  4. What does backprop pass backward, and why backward?
  5. What happens with a learning rate that's too high?
